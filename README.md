Welcome to my personal repository of **LeetCode** solutions! This repository serves as a log of my journey through data structures and algorithms, focusing on clean, efficient, and optimal implementations.

## 📌 About

Here you'll find a growing collection of problems I've solved. I primarily use **C++** for its performance and robust standard library (STL).

Each solution is contained within its own dedicated Markdown file, intentionally structured to cut the fluff and jump straight into the code. 

## 📂 Repository Structure

Files are systematically named using the convention: `<Problem_Number>_<Problem_Title>.md`

For example:
- `1_Two_Sum.md`
- `206_Reverse_Linked_List.md`
- `503_Next_Greater_Element_II.md`

Inside each file, you will find:
- The problem topic/pattern
- The optimized C++ code implementation

## 💡 Why This Structure?

Instead of complex IDE setups or heavy project folders, I prefer keeping it lightweight. Markdown allows the code to be highly readable directly on GitHub or any text editor, making it easy to review on the go.

## 🚀 How to Use

Feel free to explore the solutions! If you want to run them locally:
1. Copy the C++ code block from any markdown file.
2. Paste it into your preferred IDE or directly into the LeetCode editor.
3. Call the function with your own test cases!
